# 100 Days of Code: Python for Beginners

Welcome to my repository for the **100 Days of Code: Python for Beginners** journey! This repository is dedicated to learning and practicing Python programming from the amazing **CodeWithHarry** playlist.

## About the Challenge
The **100 Days of Code** challenge is a self-improvement and learning initiative aimed at building consistency and discipline in coding. Through this repository, I will document my progress, codes, and projects as I follow along with the YouTube playlist.

This repository is perfect for:
- Absolute beginners who want to learn Python.
- Anyone looking for a structured way to dive into Python programming.
- Developers seeking to reinforce their Python fundamentals through a fun and practical approach.

## Playlist by CodeWithHarry
This repository follows the **CodeWithHarry** YouTube playlist: **"Python for Beginners (Hindi)"**.

- **Playlist Link**: [Python for Beginners by CodeWithHarry](https://www.youtube.com/playlist?list=PLu0W_9lII9agwh1XjRt242xIpHhPT2llg)

## Repository Structure
- **Day-wise Folders**: Each day’s progress is saved in its respective folder, with clear naming to track what was learned.
- **Exercises**: Includes solved exercises and practice problems.
- **Projects**: Mini-projects built during the learning process.
